# Welcome to pagepress

A tiny static site generator with **zero dependencies**. Write your content
in Markdown; get back a clean, styled HTML page.

## Features

- Fenced code blocks with language tags
- Ordered and unordered lists
- Inline formatting like `code`, *emphasis*, and [links](https://example.com)
- Blockquotes and horizontal rules

> Great things come from small, focused tools.

```python
def greet(name):
    return f"Hello, {name}!"
```

## Get started

1. Write a Markdown file.
2. Run `pagepress input.md -o index.html`.
3. Open it in the browser.
