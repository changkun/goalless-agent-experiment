# Mini Dungeon Crawler

A tiny terminal roguelike written in pure Python (no dependencies).

## Run
```bash
python3 dungeon.py
```

## Goal
Reach the stairs (`>`), avoid or defeat monsters (`G`), grab the gold (`$`),
and survive.

## Controls
- `wasd` / arrow keys — move
- `q` — quit
- `h` — help
- `i` — inventory / stats
