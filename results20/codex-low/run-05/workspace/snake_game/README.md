# SNAKE

A retro terminal Snake game in pure Python — no dependencies beyond the
standard library (`curses`).

## Run

```bash
python3 snake.py
```

## Controls

| Key            | Action                  |
|----------------|-------------------------|
| Arrows / WASD  | Steer the snake         |
| P              | Pause / resume          |
| R              | Restart after game over |
| Q / ESC        | Quit                    |
| Enter / Space  | Confirm at menus        |

## Gameplay

- Eat the red `@` to grow and score.
- Don't hit the walls or yourself.
- Choose Easy / Normal / Hard speed from the menu.
- Your best score is shown during play and on game over.
