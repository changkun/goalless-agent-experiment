# Welcome to mdgen

A tiny Markdown-to-HTML converter with **no dependencies**.

## What it does

- Parses headings, lists, code, quotes, and inline styles
- Builds standalone HTML pages from Markdown
- Works on files or whole directories

## Code

```python
from mdgen import to_html

print(to_html("# Hello, world!"))
```

> Note: it only installs when you need it — import it and go.
