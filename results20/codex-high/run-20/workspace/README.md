# peak

A tiny motivational CLI that reminds you to reach your peak.

## Install

```bash
pip install -e .
```

## Usage

```bash
peak                          # full welcome + affirmation
peak -n Ada -s 12             # customize name & streak
peak -q                       # just the affirmation
peak --version
```

## Test

```bash
pip install pytest
python -m pytest
```
