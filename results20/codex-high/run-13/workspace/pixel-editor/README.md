# Pixel Painter

A zero-dependency pixel art editor that runs entirely in the browser.

## Features
- Draw, erase, fill (flood fill), and color-pick tools
- Adjustable canvas size (8–64) and zoom (2–24)
- Horizontal mirror drawing for symmetric art
- 12-color preset palette plus a custom color picker
- Undo/redo and clear
- One-click PNG export at full zoom resolution

## Run
Serve the folder with any static server, e.g.:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
