# md2html

Convert Markdown to HTML with **zero dependencies** — a tiny `convert(tex)`
you can read in full.

## Features

- Blockquotes, all six heading levels, and `<hr>`
- Fenced & indented code blocks with language highlighting hooks
- Nested ordered and unordered lists
- Inline `code`, *emphasis*, **strong**, and ***both***
- Links: [md2html](https://example.com) and images:

  ![sample](https://example.com/img.png)
