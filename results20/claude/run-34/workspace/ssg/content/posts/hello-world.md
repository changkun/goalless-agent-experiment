This is the first post on a site built by hand. There is no build framework,
no node_modules, no gemfile -- just **Python's standard library** and a few
thousand lines of plain text.

## Why go small

The modern web is astonishingly capable, but most of us don't need most of it.
A personal site wants to do four things:

1. Show writing
2. Link to things we love
3. Be fast
4. Be readable in twenty years

That's it. A static site generator like the one powering this page does all of
it with *zero dependencies*.

> The best tool is the one you can still run in a decade.

You can read [the source](https://example.com/ssg) any time, and it renders
to plain HTML with an `inline code` touch here and there. `until` the end.
