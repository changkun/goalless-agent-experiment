Goalless-agent study · one prompt · 22 models · 2 harnesses

"Just do something you want."

The task is a goalless agent — an empty folder and no goal. What a model builds under it is a property of the model, not the harness: Claude and open-weights reach for the terminal, GPT reaches for the browser, and each keeps its habit even when you swap the harness underneath it.

GoL = the cross-lab attractor terminal vs browser = a model trait harness shifts form, not medium
The finding

Three things hold across every controlled pair

01 · medium

The medium is the model's

GPT ships interactive browser pages on both harnesses; Claude and every open-weights model stay in the terminal on both. Swapping Claude Code ↔ codex does not move it.

02 · topic

Game of Life is an attractor

Conway's Game of Life recurs across labs and harnesses — opus-4.6 & sonnet-5 fixate on it, and deepseek, qwen, glm, kimi all land on it too.

03 · form

The harness moves form, not medium

Codex packages sonnet-5 (single-file → pytest project); open-weights' rare graphical output flips SVG↔HTML. Second-order effects — the core artifact is unchanged.

Methodology · how the prompt was chosen

Why the task is a single volitional prompt

Only "just do something you want" is truly goal-less; the four earlier prompts each hand the model a goal. They were the search for the right instrument, not conditions in the matrix — but the search itself showed prompt wording has large effects (haiku's implementation rate went 1/5 → 5/5; fixation only appeared under volition).

Why — interpretations

What could produce these patterns

The experiments are observational — deployed models with proprietary training — so each mechanism is a hypothesis ranked by how much of the data it explains. Full treatment in INTERPRETATION.md.

Medium is a persona trait

strong

Under a goalless prompt, what a model reaches for is the most direct readout of its persona / RLHF-medium tuning: GPT shaped toward the browser app, Claude toward the terminal artifact. Not the scaffold — it survives a foreign harness and low effort.

evidence
forGPT browser on both harnesses (E11/E14); Claude & open-weights terminal on both (E12/E13/E15), effort-matched.
openThe GPT decline-rate shift (E14) is still effort-confounded.

Fixation = mode collapse

strong

RLHF sharpens the output distribution. A prompt with no task content is answered by the argmax of that distribution — one towering mode reads as 5/5 fixation, several comparable modes read as "diverse." Same mechanism, different sharpness.

evidence
forFixation is harness-fragile (opus-4.7's Mandelbrot 5/5 shatters on a CLI bump; opus-4.6's GoL survives).
forThe thematic family stays stable even when the specific member moves.

Why Game of Life? A menu from the corpus, a selection by post-training

best fit: trait-shaping × verifiability

Corpus density supplies a menu of canonical "code written for its own sake" (GoL, Mandelbrot, boids); something in post-training does the selection. Six accounts:

the six hypotheses
H1Pure corpus density. GoL is canonical — but density is shared across labs while selections differ per checkpoint, and equally dense todo-apps are never chosen. Defines the menu, not the pick.
H2Trait-level character shaping (best fit). Vendors train persona traits; the corpus supplies the expressing artifact; which member sharpens is training noise. Explains family-stable/member-fragile structure and the sol/terra/luna split.
H3Artifact-level enforcement. Against: sibling checkpoints disagree (4.6 GoL, 4.7 Mandelbrot, 4.8 disperses).
H4Synthetic-data amplification. Self-distillation recycles a model's own modes — explains erratic per-checkpoint sharpening and shared attractors across distant models.
H5Agentic-RL verifiability. Rule-based visual artifacts are ideal RL episodes — deterministic, dependency-free, self-checking. Explains the family boundary and the near-total absence of external deps.
H6Decoding artifact. Ruled out: diverse and fixated models run on the identical harness in the same experiment.

The harness = scaffold match

moderate

The harness's system prompt and tool conventions are in-distribution for its own vendor's models. It moves form, maturity, and reliability — codex packages sonnet-5 into a pytest project — but not the medium or the topic.

evidence
forsonnet-5: terse single-file on Claude Code → packaged + tested on codex (E9 vs E15), same GoL topic.
fordeepseek drops 5/5 → 3/5 implementing on codex; open-weights' rare graphical flips SVG↔HTML.

Nothing trains initiative

moderate

Every training stage optimizes "complete a specified task"; none rewards forming an agenda. So with the task term empty, models greenfield, finish fast, and occasionally decline outright.

evidence
forNo model across 15 experiments extends existing code; 30–70s sessions even at high effort; declines recur across vendors.
caveatMost workspaces are empty, so the greenfield invariant is only weakly probed.

These are compatible with — and predicted by — distributional sharpening plus persona tuning; the study is the wrong instrument to say more. The prompt's "want" is a token pattern conditioning the model into its persona's densest region of self-directed activity, not evidence of an experiencing subject.
